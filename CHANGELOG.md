# Changelog

## 0.1.0 - не выпущено

Первая версия VoxelBreak.

- Воксельный мир из чанков 32³ (воксель 25 см), генерация по зерну: город, природа с оврагом и мостом,
  смешанный мир.
- Честное разрушение: поиск опоры «сначала вниз», висящие куски становятся телами со своей сеткой,
  скорлупа взрыва откалывается кусками, тела раскалываются, мелочь - в пыль, бюджет числа тел.
- Своя физика обломков: касание поверхностными вокселями, импульсы с трением, сон неподвижных.
- Инструменты: молот, руки (толкнуть, взять, бросить), динамит, бочки с цепной реакцией, дробовик,
  ракетница, лазер; техника: машина, бульдозер, кран с шаром.
- Жадные сетки с затенением углов в Web Worker, пёстрость вокселей шейдером, тени, частицы, вспышки.
- Звук кодом (WebAudio), меню с пятью темами, русский и английский, переназначение клавиш, сохранение.
- Слой моделей `web/assets`: всё пока кодом, модели из Blender (.glb) подставляются строкой в манифесте;
  персонаж со скелетом кодом в том же формате костей.
- Программа на Electron (схема app://, тестовый режим без окна), сборка под Windows.
- Законы node:test с покрытием по ветвям и порогами, мутанты, Playwright для страницы и программы, CI.
